Case Study: MindBridge App Analytics

How we used behavioral data to improve mental health outcomes for app users.

🧩 Problem

MindBridge is a mental health support app offering journaling, CBT prompts, and AI-guided check-ins. Usage was growing, but engagement was low beyond day 3. What features actually helped users stick with their wellness plans?

🔍 Approach

I analyzed anonymized in-app event data (sessions, prompt completions, mood logs) for 5,000 users over 30 days. Used cohort analysis, retention curves, and clustering (K-means) to identify engagement drivers.

📈 Outcome

Discovered that users who logged moods in the first 48 hours had a 2.3x higher 14-day retention rate. We redesigned onboarding to emphasize mood tracking. Post-launch A/B test showed a 19% improvement in user retention.

💡 Key Takeaways

  • Behavior-first segmentation is powerful in mental health products.
  • Early habit formation predicts app longevity.
  • Analytics must balance insight with empathy — we respected privacy, excluded sensitive notes, and used opt-in data only.

🛠️ Tools Used

  • SQL (BigQuery) for event funnel analysis
  • Python (Pandas, Seaborn) for clustering and visualization
  • Amplitude for user journey insights
  • Figma for presenting data-backed UI recommendations
